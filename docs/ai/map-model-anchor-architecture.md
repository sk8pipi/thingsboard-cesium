# 三维模型点位锚定架构

## 范围与正式来源

适用于 Vue Cesium 地图中的传感器、摄像头统一选点定位。模型锚点是表面安装位置，图标仍朝向屏幕，不是墙面贴花。ThingsBoard 继续拥有设备已确认的位置、UUID、权限、资产关系、遥测和告警；Video API 仍是视频唯一入口。本功能不改变摄像头身份、接口、数据库或部署。

模板 `mapPoints[].modelAnchor` 是模型相对安装位置的正式来源；`positionSource: "template"` 表示模板定位优先。用户于第二期明确批准：统一选点及模型调整只改草稿，管理员确认保存时将最终经纬度和椭球高度直接同步 ThingsBoard additionalInfo 与 SERVER_SCOPE 位置属性。运行时只读，不因刷新/遥测/模型加载写回。用户拒绝旧坐标备份，保存成功后无历史位置撤销。资产筛选决定设备集合，不参与模型坐标计算，也不扩大设备权限。

## 数据契约

- `modelId`：稳定的 `scene.models[].id`，不是临时 feature/tile ID；无显式模型的旧场景使用固定 `__base_scene_model__`。
- `modelRevision`：模型资源配置（类型、来源、assetId、URL、显式 revision）的非安全指纹。不包含模型平移/旋转/缩放参数。同 URL 的资源内容被替换时，需要显式修改模型 revision；不能自动发现服务端同 URL 内容变化。
- `frameVersion: 1`：局部坐标系是应用施加于 tileset 的 modelMatrix 之前的坐标系，不承诺是某个 glTF 网格的局部坐标。
- `localPosition`：`inverse(placementMatrix) * pickedWorldPosition`；资源内部/根瓦片变换已经体现在拾取世界坐标中，不重复乘根变换。
- `fallbackWorldPosition`：最近保存时的经纬度及椭球绝对高度缓存，不是第二套正式位置源。
- `occlusion`：`physical`（新绑定默认，图标/锚点/标签均执行深度测试）或 `alwaysVisible`（穿透总览）。
- `mapPoints[].deviceLocationSynced`：当前保存位置已成功同步标志，缺失为遗留记录，false 为待同步；不是旧坐标备份，遥测不能覆盖。位置发生变化仍须重新同步。
- `excludedDeviceIds`：模板级设备 UUID 排除集合，移除清除模板点位/模型绑定；刷新与资产筛选均遵守。
- `excludedPointTypes`：排除设备的传感器/摄像头类型，供恢复入口识别；没有类型时不猜测。
- `excludedDeviceBindings`：排除设备的业务引用（UUID、名称、类别、产品及数据采集字段），不含安装坐标、模型锚点或历史位置。业务运行时继续加载这些设备，部件使用活动点位与排除业务引用的并集，避免地图隐藏改变设备/能耗/告警统计和摄像头分类。恢复从有权限的设备读取当前位置或重新选点，不恢复旧模型绑定。后端沿用现有 dashboard/租户运行时边界，本变更不把该边界宣称为逐设备客户权限校验。

模型定位沿用地形高度加 heightOffset 和 HPR；应用统一正数 scale。加载/定位失败不伪造模型成功。模型移位后的世界坐标由当前 placementMatrix 计算；保存模板时刷新世界坐标缓存。缩放字段在原定位代码中未应用，本次统一应用，已有非 1 的 scale 配置需人工核对视觉大小。

## 交互与运行时

租户管理员通过统一“选点”新增，编辑模式点击已有点位可重新选点、移除或调整遮挡。自动点击已管理 tileset 则绑定模型（含模型道路/草地），点击地形则解除旧绑定。确认候选仅进入草稿，页面保存统一确认影响数量；弹窗部件设置不得提前持久化点位草稿。移除点位不删除设备、属性、关系、告警或视频绑定，不清空坐标，也不写回本轮已放弃的位置。暂不新增跨模板唯一性限制；同一设备跨模板使用会发生最后保存覆盖，由用户接受。

选点暂时隐藏传感器/摄像头图层并等待下一帧深度更新，停用旧编辑辅助层；校验顶层拾取对象属于已管理 tileset 后才使用 pickPosition。无模型命中时才允许地形射线拾取。已命中模型但加载不完整、能力不支持、无深度均失败，不回退地形；未知对象不猜测。取消/切换/卸载/模型重载使用代次丢弃过期结果并恢复图层。支持范围为已渲染的不透明表面，不能承诺透明玻璃、极薄边缘或粗糙倾斜摄影模型的测量级精度。

用户页和管理员页共用 CesiumMap、位置解析与变换工具。模型配置的值改变才重新加载，不因等价场景对象随遥测重建而重新加载。点位状态合并显式保护身份、坐标、heightMode、modelAnchor、positionSource。缓存标准化保留绑定字段；无效或未来版本绑定交给解析器提示，不静默改用设备位置。

## 异常与资源变化

- 模型隐藏：绑定点位隐藏，显示定位提示，不改变在线状态/资产统计。
- 加载中、失败、缺失：暂用保存位置，显示明确提示，可重试模型加载。
- 模型资源版本变化：回退保存位置并提示重新校准，不猜测新表面。
- 编辑页保存时移除被引用模型：阻止保存，提示关联点位数量，须先重新绑定或解除绑定。其他外部模板写入入口若移除模型，运行时仍提供缺失回退；本功能不新增全局后端删除门禁。
- 无效绑定：以旧坐标兼容回退并提示，不修改 ThingsBoard，不删设备。

## 迁移、兼容与回退

新字段可选，无自动批量迁移、无数据库迁移。旧点位保留原位置和遮挡方式。统一保存服务明确允许通过模型校验的绝对位置，遗留写回隔离服务保留供旧调用方使用。遗留模板定位点首次保存列入同步计划，Device 信息与属性任一步失败均报告为待重试；已成功相同坐标/属性重试时跳过重复写。不得在用户打开页面时执行迁移。

代码回退不能回滚已写入的设备坐标，只能由用户手动重新定位。旧版本可能不理解模板排除和同步标志，导致移除点重现或状态丢失，不得使用旧编辑器覆盖新模板。模型替换须重新校准，不自动推断新建筑对应关系。

## 保存一致性

模板与设备 API 是多请求流程，不声称跨 API 原子事务。保存前权限/坐标/模型校验与影响确认，执行期间禁止重复保存及编辑交互。结果区分模板状态、成功设备和失败设备，保留确认目标供重试；同步状态写入模板后可跨刷新识别未完成项。不得吞掉属性失败、显示虚假全成功或在不备份条件下自动恢复旧坐标。

执行顺序为保存模板目标与待同步标志 → 写设备信息和 SERVER_SCOPE 全部位置别名 → 保存同步结果。首次模板写入失败不写设备；后续失败保留已保存目标，取消编辑不能撤销已完成部分。恢复当前位置使用本轮内存读回基线避免多余写回，不持久化旧位置备份。路由离开/更新在保存期间被拒绝，保存目标 dashboard UUID 固定；组件更换模板完整重载，避免旧草稿混入新模板。

## 验收与非目标

自动验证矩阵往返与变换、绑定序列化、定位覆盖保护、恢复后拖动、删除保护、状态回退及真实 SFC 状态函数；真实 WebGL 验收必须另测屋顶/墙面、视角旋转、遮挡、保存刷新和双页面同步，不能用纯逻辑测试代替。

非目标：批量顶部吸附、网格贴花、法线/安装姿态、摄像头视锥、室内楼层裁切、自动检测同 URL 资源替换、大规模性能指标保证。
