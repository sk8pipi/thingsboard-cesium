# 跨模板设备位置架构

## 范围与正式来源

适用于 Vue Cesium 用户大屏、编辑页、传感器和摄像头点位。以 ThingsBoard Device UUID 标识同一设备。每个 Device 的 `additionalInfo.mapLocation` 是已确认位置的唯一正式来源：经纬度、椭球绝对高度、单调递增的 `revision` 和 `updatedTime`。旧设备无该字段时，读取 `additionalInfo` 中有效的经纬度，缺失时只读 SERVER_SCOPE 位置属性，作为 `revision=0` 的遗留位置；遗留高度缺失按 0 米兼容并在管理员确认时核对。遥测坐标和模板坐标都不是设备安装位置的正式来源。未确认且设备无可信坐标时地图提示待定位，不显示模板旧坐标。

`additionalInfo` 中的经纬度别名与 SERVER_SCOPE 位置属性是兼容投影，须从正式位置生成。原生部件仍可按自身数据源读取遥测同名字段，但地图只读运行时受保护的 `deviceLocation`，该字段最后写入响应，不能由属性或遥测覆盖。

模板只存设备引用、布局、样式、显隐、业务部件与尚未提交的显式位置草稿。`mapPoints[].longitude/latitude/height` 在新版模板中仅是草稿目标或旧版快照。`deviceLocationSynced` 只为旧数据兼容，不用于判定当前设备位置。位置更改必须由管理员确认后调用专用位置 API；编辑预览、模型加载、运行时刷新和打开页面不得写设备。

## 模型与位置

模型表面仍可拾取并生成 `modelAnchor` 草稿。编辑中的草稿可用模板模型矩阵换算世界坐标；保存确认后世界坐标成为设备正式位置，所有模板使用同一世界坐标。各模板的模型位置、旋转或缩放不得在正式展示时再次覆盖它。`modelAnchor` 可保留选点来源和遮挡方式，但不是独立位置正式来源。模型变更后若要移动设备，管理员须重新选点并确认影响所有大屏。模型隐藏或加载失败不能删除有权访问的设备点位。视频身份仍是 tbDeviceId，播放等能力仍经 Video API。

## 接口、授权与一致性

GET `/api/map-device/{deviceId}/location` 只允许有 Device READ 权限的用户；PUT 仅 TENANT_ADMIN 且须 Device WRITE。PUT 请求包含绝对位置与 `expectedRevision`。保存以 Device 的数据库版本做乐观锁，并比较位置版本；并发更改返回冲突，前端重新读取当前位置，保留未确认草稿。相同正式目标可幂等重试。设备 `additionalInfo.mapLocation` 与平铺别名随同一个 Device 保存；SERVER_SCOPE 投影失败以 `attributesSynced=false` 报告，随后按最新正式位置重试，不能用旧请求目标覆盖新版本。模板 API 与位置 API 非原子，先保存草稿与待同步标志，再提交设备位置，最后更新模板状态；任何阶段失败都须保留可重试状态，不报全成功。

现有 dashboard/租户运行时仍沿用原权限边界；本变更不声称 SSE 增加逐设备客户权限。新位置 API 必须执行 Device 权限检查。SSE 继续按现有约两秒轮询，实际可见时间含查询和网络耗时。前端只接受较新 revision，断线重连读快照；已打开编辑页的未提交位置草稿不被外部事件抹除，旧基线保存冲突后要求人工核对。

## 迁移、兼容和回退

管理端提供只读盘点多个模板中同 UUID 的位置、模型绑定和设备正式/遗留位置，读取不完整时明确标记。冲突由管理员逐点选择设备当前位置、某模板绝对位置或重新选点。旧模板位置不能因普通布局/样式保存而自动写回设备。新模板 version 9；旧 `positionSource: template` 和 `deviceLocationSynced` 仅作为迁移资料。移除/恢复只改变当前模板显隐；直接恢复读取设备当前位置，不恢复旧模型锚点。

不自动批量迁移真实设备、不备份旧坐标、不改变 SQL schema、视频身份、部署或网络。代码回退不能撤销已提交的设备位置；旧版本编辑器可能再次用模板坐标覆盖，回退期须停用位置写入口并逐设备人工重新定位。

## 验收与决策记录

同一 UUID 在不同模板显示相同经纬度与绝对高度；一屏保存后其他已开屏经 SSE 更新，刷新后仍一致；纯样式保存不写位置；并发位置保存产生冲突；旧模板不隐式迁移；新旧 SSE 不回退；模型、地形选点与高度正确；排除与恢复、部分失败与重试保持；无权限用户不能读取或写入位置。自动测试之外，还需真实双浏览器 Cesium/WebGL 和权限联调。

2026-09-26：用户批准由模板定位优先改为设备全局唯一位置，并批准位置 API、版本冲突、显式旧数据处理与模型世界坐标规则。RIO 与冻结接口见 `docs/changes/map-device-location/decisions.md`。
