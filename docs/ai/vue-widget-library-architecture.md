# Vue 原生部件适配与液态玻璃

## 范围与正式来源

适用于 frontend/ 的资源部件列表、部件包列表、普通仪表盘、Cesium 大屏和点位详情。ThingsBoard 后端仍拥有资源定义、实体、遥测、属性与权限；不改 Angular UI、数据库、Gateway 或视频接口。

backend/application/src/main/data/json/system/widget_types/ 是本仓库原生定义的参照源。scripts/generate-native-widget-catalog.py（位于 frontend/）生成 nativeWidgetCatalog.generated.json 兼容索引；该文件仅是编译期投影，不代替后端资源目录。资源详情和下载使用后端完整定义。

## 适配契约

- 521 个原生 JSON 定义逐项列入目录。目前 478 项提供 32 类 Vue 基础实现，近期新增风速风向、罗盘、温度计刻度、RPC Button、多属性更新、实体与告警计数、属性卡片、告警表格、实体层级、实体表格和资产/设备管理表、两张网关统计曲线、设备认领、两种图片属性输入、三种位置输入、拍照输入、LED 指示灯、开关/按钮/旋钮/滑块/步进器，以及 12 个高级控制、RPC 与 GPIO 部件。基础适配数只表示有 Vue 运行入口；每项完整原生行为仍需单独验收。
- “基础适配”表示按对应类别重新配置 Vue 数据显示，不等于原生控件全部行为或造型复刻。提供水平/垂直数值布局、标签位置、圆弧与线性仪表等设置，外层保持玻璃布局。原生全部高级布局、脚本、动作、函数数据源和后处理不执行。
- 另有 43 个 JSON 定义没有 Vue 运行入口。其中地图与位置 16 项、卡片/导航/平台入口 18 项按产品范围从 Vue 部件库隐藏；其余 9 项继续显示为待适配。原有本地部件继续可用。
- 通过原始 fqn 精确关联，不按名称或文件名猜测。完整定义的模板与控制脚本指纹用于检测版本变化；不是安全签名。未知定义保留原始 JSON，不能自动运行。
- config.native 保存 version:1、原始 fqn、family、时间/展示配置及 rawSource；config.datasources 保存实体与字段。DashboardWidget.widgetKey 使用 native_ 家族键。归一化保留原始 typeFullFqn 和配置；原始脚本始终只作为数据存储。

全量适配源清单还包含后端安装时从 SVG 元数据生成的 160 个 SCADA 定义，共 681 个源；不将这些源遗漏或当作 JSON 适配数。full-adaptation-inventory.json 分别记录源身份与基础家族，目前没有任何条目获得全部原生行为一致性验收。

## 数据与配置

NativeWidgetBrowser 的原生包 → 部件是共同浏览入口，NativeWidgetPicker 是独立抽屉包装；大屏添加抽屉直接嵌入 Browser，顶部保留导入。原生分类与图片来自仓库中的 ThingsBoard 系统定义；nativeWidgetBundles.generated.json 是 32 个包的编译期投影。浏览时先显示该投影，再按原始标识合并服务器资源及完整定义；接口返回空数组、部分结果或请求失败均不能清空原生目录。服务器自定义版本在选择时仍需校验适配签名。图片沿用内嵌原图和认证图片 API，按可见区域延迟加载，共用请求随最后一个使用者卸载释放。

NativeWidgetComposer 提供基础/高级分组，在确认前维护独立草稿；点击“预览”复制配置，预览与正式展示共用 NativeWidgetRenderer。点位详情锁定当前设备 UUID，添加/编辑/删除均不提前保存点位；删除、重新编辑使用稳定部件 ID。

native.presentation/chart/table/progress/gauge/pie/latestBar/radial/range/aggregate/liquid/state/battery/signal/wind/input/locationInput/photoInput/ledIndicator/multiInput/rpcButton/control/advancedControl/count/attributeCard/alarmTable/deviceClaim/entityHierarchy/entityTable 是 version:1 的可选增量设置，序列设置位于 dataKeys[].settings.native。旧配置补默认值，保留 false/0/空值及未知扩展；地图与点位保存保留未适配定义，禁止执行未知脚本。坐标轴最多 4 个，删除时将引用移到第一个轴；图例选择与缩放在数据轮询时保留，修改配置时按保存设置重置。当前能力字段清单见本次任务 configuration-coverage.md。

control 家族覆盖 `switch_control`、`round_switch`、已弃用的 `slide_toggle_control`、`knob_control`、`power_button`、`single_switch`、`toggle_button`、`slider` 和 `value_stepper`；`command_button` 复用 RPC Button 家族。声明式配置保存状态读取方式、字段或读取 RPC、写入 RPC、持久请求、范围、步长、精度、单位、标签与颜色；预览禁发 RPC，正式操作仅向设备发送已有认证 RPC。原生 JavaScript 值转换不执行，现代控制部件的属性/遥测写入动作和全部高级造型仍待补齐，因此不计入完整一致性验收。

advancedControl 家族精确覆盖剩余 12 个控制、RPC 与 GPIO 定义。GPIO 控制使用原生引脚清单和读写方法，GPIO 面板保留 3 针或 40 针静态布局；持久 RPC 表、调试终端、远程 Shell、服务 RPC、状态读取和设备属性更新均复用现有认证 API。动作按钮与双段按钮只允许不执行或站内/HTTPS 声明式链接。预览禁发 RPC、禁写属性、禁删除请求且不跳转；配置随模板保存并由同一 Renderer 重新消费。远程 Shell 不提供任意浏览器脚本执行，但正式运行会把用户输入作为设备 RPC 命令发送，后端权限和真实设备协议仍须现场验收。

14 个标量输入定义只通过原始 fqn 白名单选定写入模式与范围；`input_widgets.update_json_attribute` 可在属性与遥测之间切换，属性可选服务端或共享范围。两类输入都限一个实体和一个同范围字段；共享属性限设备，切换目标时清空旧字段并重新加载对应范围的键。运行时需再次验证实体与字段绑定，预览禁写，正式部件仅由用户操作触发已有认证 Telemetry API，并在写入后回读。JSON 输入只接受对象或数组，空的非必填值保存为 `{}`。两种图片属性输入仅接收常见位图的 Data URL；三种位置输入成对保存经纬度，按原范围写入遥测或属性，仅在正式部件主动请求浏览器定位。多属性更新可混合多个字段并按范围分组写入与回读；原始 get/set 函数脚本仍不执行。后端继续按现有 WRITE_ATTRIBUTES/遥测权限校验，Vue 不持有额外凭证；真实权限和浏览器定位仍需现场验收。

拍照输入只在正式部件主动打开相机，按尺寸与格式生成照片；可复用已有图库上传 API 再保存链接，也可直接写入 Data URL。LED 指示灯预览禁发 RPC，正式部件可用普通或持久双向 RPC 检查设备状态，再读取属性/遥测并更新灯态。自定义 JavaScript 值解析不执行；图库上传和字段写入不是原子事务，写入失败可能留下未引用图片。相机权限、持久 RPC 状态和真实设备返回均待现场验收。

实体与告警计数使用既有认证 Query API，配置实体类型/名称前缀、告警状态/等级/类型和最近时长；无遥测数据源，预览与运行共用查询组件。点位入口用 `singleEntity` 限定当前设备。查询失败显示错误，不冒充零计数；不执行原函数数据源。完整实体别名、原生动作与全部视觉设置尚未验收。

属性卡片复用认证最新遥测与属性读取，按数据源分组显示字段标签和值，可隐藏空值并调整标签列宽。告警表格通过既有认证告警 API 查询，支持搜索、状态/等级筛选、排序、分页、详情与点位设备限定；确认/清除只在正式部件由用户明确点击触发，预览禁写。原生分配、活动记录、列显示和批量操作等行为尚未重写，均不计入完整一致性验收。

网关包的 `gateway_custom_statistics` 和 `gateway_general_chart_statistics` 仅按原 `tb-flot-line-widget-settings` 时序曲线语义复用现有 Vue 图表与认证遥测读取；其原始函数示例不执行。网关配置、连接器、日志和管理操作仍须独立核实接口和权限。

设备认领使用既有认证 `/api/customer/device/{deviceName}/claim` 接口。配置只保存标签、按钮文字和是否要求密钥；设备名与密钥仅在正式部件运行时输入，密钥不进入模板。无密钥模式发送空对象，沿用后端默认认领密钥；预览禁写。认领结果由后端权限和响应决定，尚未以真实客户会话验收。

实体层级使用已有认证关系信息 API，单个设备或资产作为根节点，声明式配置关系类型、方向、最大深度、名称排序和默认展开；每层按需读取并排除循环关系。原生任意节点查询/文本/图标函数不执行，也不计入完整一致性验收。

实体表格通过已有认证实体查询 API，声明式选择设备/资产、搜索分页、名称排序和最多 16 个最新遥测/属性列；点位入口限当前设备。资产/设备管理表复用认证实体与属性 API，支持新增、编辑名称/类型/标签/经纬度、二次确认删除和动作开关；配置预览强制只读，正式运行仍受后端权限控制。原始函数数据源与任意脚本不执行。

Bars 使用 latestBar 家族，读取最新遥测或对应范围的属性，不走历史查询和时间窗口。Doughnut / Horizontal doughnut 精确匹配原始标识，提供内径、排列方向、图例方位和中心合计格式；合计仅包含非负数字，无可用数据时显示空值占位，不伪造零值。图表使用明确字体以保证 Canvas 字号配置生效。

设备配置筛选使用 deviceProfileId；属性区分 CLIENT_SCOPE、SERVER_SCOPE 和 SHARED_SCOPE。资产选择读取资产自身字段，下属设备汇总继续使用既有资产聚合部件。一个部件最多 8 个实体、32 个字段；仪表最多 4 个字段。

Renderer 自行维护数据读取生命周期，注册表的 dataProvider 为 static，以免旧单设备运行时重复订阅。输入部件的写入仅由明确的用户提交触发，预览只读。数据服务复用现有认证遥测 API，最新值和历史值分别查询；多实体同名字段使用独立标识。历史范围最多 31 天，支持服务端 NONE/AVG/MIN/MAX/SUM/COUNT 聚合、绝对历史和滚动时间窗。

共享客户端最多 6 个在途请求，同一请求在途去重；每轮完成后再轮询，5–300 秒间隔。固定历史图线部件只查询一次；日历窗口继续轮询，聚合卡片含独立最新值位置时也需持续读取。卸载和配置变化用代次丢弃过期结果，并停止后续调度；已经发出的 HTTP 请求不保证中止。历史每序列保留最近 2000 点，额外探测一条判断截断并提示。空值、失败和数字零明确区分，不伪造数据。

时序图与数值曲线的横轴使用配置的完整时间范围。滚动模式每秒按浏览器当前时间推进横轴，无新遥测或空数据时仍推进；数据读取保持上述轮询间隔。固定历史使用指定起止时间，切换模式及卸载时清理滚动计时器。

雷达图使用雷达坐标与独立字段图例；极区图使用极坐标柱形。范围图限定一个遥测字段，按历史数值区间着色，提供区间图例、边界线和填充透明度；不读取无用的最新值，图例选择随轮询保留。

聚合卡片限定一个实体、一个遥测字段，最多五个数值位置。每个位置分别读取服务端整窗聚合，不用截断的绘图样本计算均值；NONE 当前值读取最新遥测，比较值读取上一窗口最后一条。位置独立配置聚合、比较偏移、上一值/差值/百分比、单位、精度、字号、颜色和箭头，失败不污染其他位置。零分母百分比返回 100，遵循原生算法；空数据不伪造零。关闭曲线后停止图线历史查询。

window.calendar 为 version:1 可选字段，提供今天/本周（周一开始）/本月至今，按 UTC 计算；realtime=true 时优先采用滚动时长，否则 calendar 优先于保存的绝对起止。每秒推进可见轴，查询按原刷新间隔推进；跨日/周/月重新计算起点。聚合卡默认本月至今，比较支持固定或日历窗口，月/年偏移钳制月末。当前未支持任意时区、夏令时和全部原生日历类型，不宣称这些能力已兼容。旧的无 calendar 配置仍沿用原行为；旧前端会忽略新增字段，回退前保存模板 JSON。

液位容器使用原始十种 SVG 的静态节点投影 nativeLiquidShapes.generated.json，通过 Vue VNode 绑定液面位置、颜色和文本，每实例重写 SVG ID/引用。只接受本仓库生成资产，不运行导入 SVG 或脚本。单实体单主字段读最新遥测或指定范围属性；形状、容量、容量单位和显示单位可独立绑定属性，按范围合并读取。输入与显示容量以升换算，数据零值保留，仅液面位置裁剪 0–100%；失败显示提示并隐藏液体，不冒充有效读数。支持三种布局、四组独立颜色区间、字号与容量样式、底板、500ms 液面过渡及独立提示单位/精度。日期格式复用 presentation。内层 SVG 滤镜移除，玻璃由宿主负责；字体族/字体粗细、图标、原生提示框所有样式和脚本动作仍未完全复刻，列为完整一致性缺项。

## 展示与保存边界

外层 WidgetHost 宿主使用现有 widgetSurface.css 和 WidgetAppearance；Renderer 内部透明，不增加 backdrop-filter。大屏全局玻璃设置优先于单部件设置。点位嵌套容器只保留高光与边框，由弹窗外层执行一次模糊；不改变地图位置、模型锚点或视频业务身份。

大屏仍由原模板显式保存；点位配置先返回编辑草稿，再由既有确认保存流程持久化。普通仪表盘继续写 configuration.__vueWidgets/__vueLayout。资源导入入口仅本地解析与预览，不覆盖后端部件；大屏导入保留原始定义并在添加时重新选择数据。

## 兼容、回退与验收

无数据库迁移、无用户模板批量重写。新配置为增量保存；旧前端不认识 native_ 键，不能用旧编辑器覆盖已含新部件的模板。回退代码前保留模板 JSON，可在当前编辑器删除新部件后再回退；历史设备数据和位置不受影响。

单元测试覆盖目录逐项识别、未知/自定义版本拒绝、多实体同名字段、属性范围、时间窗口、聚合、截断、失败和卸载。SFC 行为测试覆盖添加/重新编辑与草稿不提前保存。真实 API、客户权限、保存刷新和 Cesium WebGL 验收独立记录，不能用模拟视觉夹具代替。
