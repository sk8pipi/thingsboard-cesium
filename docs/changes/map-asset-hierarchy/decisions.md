# 大屏资产树决策

## 已批准方案
用户批准上一轮完整方案。复用 COMMON/Contains 的 Asset→Asset/Device 关系，目录只展示可访问资产；入口继续仅 CUSTOMER_USER。展开不筛选、名称单选任意层级。搜索保留匹配节点祖先，父级匹配时保留下级。无可见父级的资产作为根，多父级按路径展示，循环截断并提示。

## 数据与失败约定
全目录及所有直接关系加载成功后原子替换树，不发布不完整层级。目录刷新使缓存失效并重新解析当前选择；30秒内同一页面共享关系缓存，失败不缓存。设备点位筛选继续复用原 BFS 和设备 UUID，报警、能耗与楼层模型不联动。

## RIO
- Risks：关系环、多路径膨胀、过期响应、权限变化和首次请求量。采用访问路径去环、规模限制、并发6及请求代次保护。
- Impact：仅客户用户的大屏资产目录与点位选择；不改变公共接口和数据库结构。
- Options：采用前端构树；平铺路径不够直观，后端聚合留待规模需要时另行设计。

## 回退
回退本次前端文件即可恢复平铺目录，已有资产关系与本地资产ID选择不需迁移。
