- ThingsBoard 设备配置是分类正式来源：配置 ID 关联，配置名称显示。deviceType 仅遗留迁移输入，不覆盖已知配置。
- 样式逐字段继承：单点 > 模板配置规则 > 原生配置图片（图标）> 内置 > 通用。规则绑定配置 ID，名称仅快照。

- 用户页不持久化迁移；编辑页保存迁移，保留旧模板快照、显式处理多样式冲突。保护原坐标/锚点和统计设备集合。
- 运行时添加受保护的设备元数据，配置图片按配置去重。利用现有 runtime 刷新链路更新，避免每点额外查 deviceType。

## RIO
- Risks：旧样式冲突/丢失、改名失效、异步元数据覆盖、摄像头路由错误、图片失败。用 ID 规则、迁移预览/快照、元数据隔离、视频边界和回归测试控制。
- Impact：模板 JSON 与 runtime 响应增量扩展，前端地图与统计共同迁移；无 schema、权限或部署拓扑修改。
- Options：已选择统一来源并复用配置图片；不采用仅改文案或继续按名称/客户端属性分类。
- 回退：保留原模板快照；旧编辑器不覆盖新模板；代码回退不改设备数据。迁移由管理员保存模板触发，当前不执行实际模板批量迁移。
