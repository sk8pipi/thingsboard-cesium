## 2026-09-01 满铺修正验证

- 1908×894 编辑器舞台专项计算：部件画布宽度等于容器宽度、`left=0`，高度等于容器高度减响应式顶栏高度。
- 1908×956 真实运行页浏览器检查：根容器与 Cesium 均为 1908×956；顶栏约 56.65 px，部件可用内容高度约 899.35 px。
- 当前本地浏览器用户不是 `TENANT_ADMIN`，路由权限阻止直接进入地图部件编辑器，因此真实模板视觉效果仍需用户在现有租户管理员会话中复核。
- P1/P2 同步专项：同一份 21 行可渲染布局在运行页与编辑器均解析为 21 个有效行；位于第 40 行但已无对应部件数据的残留网格项不会参与计算，网格总高度与顶部栏下方画布高度一致；空模板仍保留 25 行兼容回退。
