## 目标

- 让 Cesium 地图、地图部件、顶部栏和业务弹窗按实际地图容器尺寸自适应。
- 支持 1280×720 至 3840×2160，以及 16:10、超宽屏、侧栏切换和全屏状态。
- 保持现有模板部件 `x/y/w/h` 逻辑坐标兼容，避免整页 DOM 缩放影响 Cesium 清晰度和拾取。

## 非目标

- 不修改 ThingsBoard 后端、数据库、设备身份、遥测或视频 API。
- 不新增生产依赖。
- 不为手机竖屏提供独立的大屏编排模板；窄屏只保证可访问和可操作降级。

## 已批准方案摘要

- 使用 1920×1080 作为 UI 缩放基准，保留 12 列和 25 个设计行。
- Cesium 原生铺满容器；部件层铺满顶部栏下方全部可用区域，GridStack 横纵尺寸分别按实际容器分配。
- 使用 ResizeObserver 监听实际容器，统一驱动 GridStack、Cesium、顶部栏和弹窗。
- 模板配置升级为 v6，旧 v5 模板加载时补齐响应式元数据且保留原布局坐标。

## 验收标准

- 常用分辨率和全屏切换后地图无黑边、部件无纵向失真和非预期滚动条。
- 程序化尺寸变化不修改模板逻辑布局，不重连遥测数据。
- 顶栏、视频弹窗和传感器弹窗以地图容器为边界，不因应用侧栏产生越界。
- 旧模板无需人工迁移即可加载。
- 前端类型检查、专项测试、相关 ESLint 与生产构建通过，或如实记录既有阻塞。
