# 关联实体选择器决策

## 已批准方案
- 使用现有ThingsBoard分页接口，不新增后端API。
- 每页50条，下拉滚动到底部时按hasNext加载下一页。
- 输入搜索词后防抖调用服务端textSearch并从第0页重新加载。
- 使用请求序号忽略过期响应，按实体ID去重。
- 编辑关系时保留当前选中项；切换实体类型时清理旧ID。
- 同步修复关联弹窗已有分页实体的相同50条限制；没有可用前端加载分支的类型不继续暴露为空选项。

## RIO
- Risks：异步响应乱序、重复分页、编辑项不在当前页、快速切换残留旧ID。
- Impact：只影响新增/编辑关系弹窗；关系保存接口、权限和数据结构不变。
- Options：超大pageSize和一次性全量加载实现简单但大租户性能差；采用服务端搜索与渐进分页。

## 回退
回退关联表单和新增分页工具即可恢复原行为，不涉及数据迁移。
