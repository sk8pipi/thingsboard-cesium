## 目标
修复资产、设备详情中新增关联时只能看到第一页50条实体的问题，使用户能够通过滚动分页和服务端搜索访问当前租户内全部有权限实体。

## 验收标准
- [x] 设备和资产超过50条时可继续滚动加载至末页。
- [x] 可按名称搜索尚未加载的设备和资产。
- [x] 快速切换实体类型或搜索词时旧响应不覆盖新结果。
- [x] 编辑已有关系时保留不在当前页的选中实体名称。
- [x] 切换实体类型时清除旧实体ID。
- [x] 切换实体类型时保留关系类型、固定端实体和其他已有表单值。
- [x] 新增关系时只校验当前方向可见的实体类型和实体ID，不校验隐藏的另一侧字段。
- [x] 不修改后端、数据库或权限模型。
