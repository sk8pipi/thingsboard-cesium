- 当前状态：待人工提交
- 当前主 Agent：主 Agent
- 最后更新：2026-09-03

## 目标

- 用户大屏默认显示模板中的全部传感器和监控点位。
- 在大屏顶部提供资产选择入口，选择资产后只显示该资产及其子资产关联的点位。
- 传感器和摄像头使用同一筛选规则，切换资产时正确关闭已被隐藏点位的弹窗和视频会话。
- 资产选择仅属于当前用户的运行时视图，不修改租户管理员保存的地图模板布局。

## 非目标

- 本期不联动筛选设备统计、能耗、报警趋势等大屏部件。
- 不改变 ThingsBoard Device、摄像头 `tbDeviceId`、视频播放 URL 或 Video API 契约。
- 不新增数据库表、生产依赖或新的点位身份模型。
- 不修改租户管理员的部件拖拽、保存和分辨率自适应语义。

## 已批准方案摘要

- 默认选择“全部资产”，保留当前全部点位行为。
- 首期采用单选资产，支持搜索和清除；资产筛选包含所选资产的后代资产。
- 通过 ThingsBoard Asset/Entity Relation 解析资产与设备关系，最终用 ThingsBoard Device UUID 与地图点位 `entityId` 匹配。
- 选择结果按用户和大屏范围保存在浏览器本地；资产失效或无权限时回退“全部资产”。
- 优先复用现有受权限保护的 ThingsBoard API；若现有 API 无法安全满足递归查询，再提交后端聚合接口 RIO 供确认。

## 验收标准

- 首次进入和选择“全部资产”时显示全部传感器与监控点位。
- 选择任一资产后，仅显示该资产树下关联设备对应的地图点位，重复关系不会产生重复点位。
- 无关联设备的资产显示空状态且 Cesium 保持可操作。
- 切换筛选后，被隐藏点位的传感器详情和摄像头播放窗口会关闭并释放运行状态。
- 刷新页面后恢复当前用户上次有效选择；无权限或已删除资产自动回退全部。
- 不影响管理员编辑页模板保存、用户页响应式布局、摄像头播放和现有点位实时状态。
