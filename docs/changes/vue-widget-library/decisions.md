## RIO
Risks：配置字段丢失、原生代码不能运行、预览与实际不一致、错误订阅、液态玻璃多层模糊拖慢。通过显式适配清单、保留原定义、同组件预览、校验及隔离测试控制。
Impact：Vue 部件管理、编辑、导入与运行扩展；沿用后端 API/鉴权/数据库和视频接口。无新生产依赖、无批量迁移。
Options：采用原生类别复用基础 Vue 组件与预设；不采用 Angular 内嵌冒充 Vue 重写，不自动执行导入代码，不以统一折线图替代全部部件。
