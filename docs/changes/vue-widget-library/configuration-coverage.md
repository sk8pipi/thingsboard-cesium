# 当前配置链路与验收范围

2026-09-24：本表记录当前代码提供的配置，不代表 ThingsBoard 所有配置已经复刻。正式运行边界见 docs/ai/vue-widget-library-architecture.md。

## 选择与添加

大屏编辑 → 添加部件 → 原生部件包 → 部件 → 基础/高级配置 → 预览 → 添加。导入按钮位于抽屉顶部，已导入资源单独进入；内置部件仍用原有缩略图及配置入口。普通仪表盘和点位详情复用原生两级浏览和同一配置器。

32 个原生包与部件归属由后端目录生成。本地系统目录先显示，服务器资源按 alias/fqn 合并；尚未适配的条目显示待适配。原图是原始内嵌图片或现有认证图片 API 引用，不用生成图替代。

每个编辑器先克隆草稿，预览再克隆快照；正式添加/应用发出完整 JSON。三个宿主沿用既有显式保存入口。新增配置是 version:1 的可选字段，缺失时补默认值，已有 false、0、null、空字符串、空数组和扩展字段保留。

## 已知边界

- 当前 521 个 JSON 定义中 478 项基础适配，共 32 个运行家族；43 项没有 Vue 入口，其中 34 项按产品范围从部件库隐藏、9 项保留为待适配。安装生成的 160 个 SCADA SVG 源仍待适配。全量源清单共 681 项；基础适配数不是完整验收数，完整原生一致性验收仍为 0。
- 尚无 Vue 运行入口的 JSON、主动排除项与 160 个 SCADA 符号逐项名单及当前技术边界见 [vue-rewrite-pending.md](vue-rewrite-pending.md)。
- 不执行原始 Angular 脚本、函数数据源和后处理脚本。完整实体别名、仪表盘时间窗口继承、任意时区/全部日历类型、原生全部动作和高级布局尚未提供。
- 带标签柱图修正为历史语义；旧模板如果曾配置属性字段，重新编辑时需选择遥测与历史范围，原始配置不会自动删除。
- 前端回退不会理解新增展示选项，回退前备份模板 JSON；不能承诺回退后外观一致。没有数据库迁移或批量模板重写。
- 已跑证据仅见 verification.md。隔离夹具没有真实模板写入、客户权限或设备 API 验收；原图 API 引用需在 ThingsBoard 服务可用时验证。

液位字段行只提供实际消费的字段和精度；单位和颜色使用液位专用配置，不显示无效的通用设置。液位高级提示框样式、字体族/粗细及脚本动作仍未完整适配。
