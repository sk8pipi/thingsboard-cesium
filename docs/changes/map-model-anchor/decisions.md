# 模型点位锚定决策

## 第二期批准（2026-09-08，覆盖下方第一期定位写回规则）
用户批准完整合并方案并明确要求实现：一个选点入口自动命中模型或地形，模型道路/草地亦跟随模型；新增传感器/摄像头、重新定位和跨模型/地形切换共用流程。编辑仅草稿，保存确认后将最终经纬度及高度直接同步 ThingsBoard，不备份旧坐标。当前模板移除只保存设备 UUID 排除记录并清除绑定，不删设备、不清空坐标；提供恢复设备当前位置或重新选点恢复。资产切换/刷新不得重现排除点；业务统计口径不变。无跨模板唯一性限制，重复使用导致最后保存覆盖的风险由用户接受。

### 第二期 RIO 与边界
- 2026-09-09 实现补充：为兑现已批准“移除只影响地图、不改统计”，模板排除集合另保留类型及业务引用（类别/采集字段），不保留安装坐标与模型锚点；后端采集器纳入该引用。恢复时的内存位置读值仅防止多余写回，不是旧位置备份。无数据库/公共 API/授权模型变更。
- Risks：多请求部分成功、模型异常错误写回、隐藏点刷新复现；保存前校验、确认数量、结果分项报告与重试，移除记录持久化。保存后无历史位置回退。
- Impact：前端模板 JSON 增加可选排除字段，模型定位明确写设备坐标；保持设备 UUID、权限、资产/视频关系与 API、数据库、部署不变。只读运行时绝不写坐标。
- Options：用户选择统一自动拾取和直接坐标同步，拒绝位置备份及跨模板限制；不采用两套独立选点入口。
- 迁移：旧数据可读，首次保存列明待写回点；不加载即写回、不执行自动批量迁移。旧版本不理解排除字段，回退代码前必须理解移除点会重现；设备坐标不回滚，用户手动重新定位。

## 批准
用户在完整方案后明确要求实现。采用第一期表面锚定 Billboard，非纹理贴花。ThingsBoard 是设备真实位置正式来源，模板内可选模型锚点是模板展示位置正式来源；不隐式写回设备位置。

## 契约
稳定 scene model ID + 资源 revision + 定位坐标系版本 + localPosition + 世界坐标回退。定位坐标系使用应用施加的 tileset.modelMatrix（资源内变换已含在拾取世界点中）；不保存临时 tile/feature ID。绑定点位优先解析锚点，遥测仅更新状态。模型隐藏时隐藏点位，加载失败/资源变化回退并提示。解绑保留当前展示位置为模板手动覆盖，不写设备。

## RIO
- Risks：坐标覆盖、异步模型重载、低 LOD/透明表面误选、深度裁切、模型删除后悬空。严格指定模型拾取、代次保护、回退提示、明确删除保护与遮挡选项。
- Impact：仅前端模板 JSON 增量字段与展示定位规则；设备真实坐标、UUID、权限、资产关系、Video API、数据库与部署不变。
- Options：单纯存高度不能跟随模型；自动竖直吸附不能覆盖墙面。采用模型局部锚点；批量屋顶与贴花后续独立实现。

## 兼容/迁移/回退
旧点位无新字段时继续原行为，不批量迁移。新绑定保留经纬度绝对高度回退；旧版本可显示回退但可能在保存时丢失新字段，回退前备份模板且不要用旧编辑器覆盖绑定模板。解除绑定可恢复模板手动位置，显式切回设备定位才使用设备源。
